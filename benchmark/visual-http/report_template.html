Nio HTTP server benchmark

Closed-loop load: every connection sends one request, reads the full response, and repeats — so throughput = connections ÷ latency by construction. CPU is % of one core (a multicore server can exceed 100). The first second of each stage is dropped from the aggregates as settling time. Each run ends with an idle tail — every connection closed, no load at all — so the end of the memory chart, and the “idle” row of each table, show how much of the load's memory the runtime gives back.
